# Claude Skills爆了，我早写了

这周 GitHub 上 awesome-claude-skills 冲上 Trending，1000+ 现成 skill 随便挑。但我早给自己写了个——把双平台发文流程焊死了。

你让 AI 编程助手发一次双平台文，它干得挺好。可第二天再说「再发一篇」，它又把流程问一遍：封面多大、插画啥格式、脱钩查哪几个词。

问题不在模型笨，是**流程只存在对话里，没存在文件里**。步骤一多，隔一晚就忘，必漏。我前后漏过封面、漏过正文插画，读者还来问「图呢」。

我的做法：把 9 步流程 + 资产清单 + 已知坑，写成一个 skill。下次加载就走，不跳步、不漏资产、双版不串台。

最实在的验证：之前连着产出两篇，隔了一夜我还记得清清楚楚——因为流程在文件里，不在我脑子里。

你给 AI 编程助手写过 skill 吗？写第一个最难的是哪步？
